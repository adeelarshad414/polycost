# Code of Conduct

PolyCost is intended to be a practical, respectful open-source project for cloud,
FinOps, architecture, engineering, and product communities.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but accept correction gracefully.
- Keep technical disagreement focused on facts, tradeoffs, and project goals.
- Welcome contributors with different experience levels and backgrounds.
- Give clear feedback without personal attacks.

## Unacceptable Behavior

- Harassment, intimidation, threats, or discriminatory language.
- Personal insults, trolling, or sustained bad-faith disruption.
- Publishing private information without explicit permission.
- Sharing secrets, customer data, provider account data, invoices, or confidential
  pricing agreements.
- Using project spaces for spam or unrelated promotion.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, discussions, or pull requests
that violate this policy. Maintainers may also temporarily or permanently restrict
participation when needed to protect the project and its contributors.

## Reporting

If you see behavior that violates this Code of Conduct, contact the maintainer
privately. For security vulnerabilities, use the process in `SECURITY.md` instead.
