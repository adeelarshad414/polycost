# Support

PolyCost is an open-source project. Support is community-oriented unless a separate
commercial support agreement exists.

## Where to Get Help

- Use GitHub issues for reproducible bugs, documentation gaps, and feature requests.
- Use pull requests for proposed fixes.
- For security issues, do not open a public issue. Follow `SECURITY.md`.

## What to Include

For bugs, include:

- PolyCost commit or release version.
- Runtime mode: local npm, Docker Compose, or hosted deployment.
- Node.js and npm versions.
- Browser and operating system for UI issues.
- Sanitized request payloads, diagrams, logs, or screenshots.
- Expected behavior and actual behavior.

Never include secrets, provider credentials, customer diagrams, private invoices,
or confidential pricing agreements.

## Scope

The project can help with:

- Running PolyCost locally.
- Understanding supported cloud-cost modeling paths.
- Parser, comparison, report, and UI bugs.
- Documentation and setup issues.

The project does not provide:

- Cloud vendor support.
- Legal, accounting, procurement, or tax advice.
- Invoice-grade billing validation.
- Emergency production incident response for third-party deployments.
