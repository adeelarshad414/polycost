# PolyCost Frontend Integration Contract

Base URL: `/api/v1`

This document reflects the implemented backend contract. Request-time endpoints read the database cache only; provider pricing and currency APIs are used by scheduled jobs.

## Pricing Compare

`GET /pricing/compare`

Query params:

- `instanceFamily`: `general-purpose | compute-optimized | memory-optimized | storage-optimized | accelerated-computing`
- `vcpu`: positive number
- `memoryGb`: positive number
- `region`: canonical region such as `us-east`
- `term`: `on_demand | reserved_1yr | reserved_3yr`

Response:

```json
[
  {
    "provider": "aws",
    "providerSkuId": "m7i.xlarge",
    "skuId": "uuid",
    "pricePerHour": 0.192,
    "term": "on_demand",
    "region": "us-east-1",
    "currency": "USD",
    "effectiveDate": "2026-06-29T00:00:00.000Z"
  }
]
```

Notes:

- Empty array means no normalized cached SKU matches the request. Do not call live pricing from the frontend as a fallback.

## Pricing Breakdown

`GET /pricing/breakdown`

Query params:

- `workloadId`: UUID from `POST /workloads`
- `term`: optional, defaults to `on_demand`

Response:

```json
{
  "workloadId": "uuid",
  "term": "on_demand",
  "providers": [
    {
      "provider": "aws",
      "region": "us-east-1",
      "compute": 280.32,
      "storage": 11.5,
      "egress": 90,
      "total": 381.82,
      "currency": "USD"
    }
  ]
}
```

## Workloads

`POST /workloads`

Body:

```json
{
  "instanceFamily": "general-purpose",
  "vcpu": 4,
  "memoryGb": 16,
  "region": "us-east",
  "instanceCount": 2,
  "hoursPerMonth": 730,
  "storageGb": 500,
  "storageTier": "standard",
  "egressGbPerMonth": 1200
}
```

Response includes the submitted fields plus:

- `id`
- `createdAt`
- `updatedAt`

## Budgets And Alerts

`POST /budgets`

Body:

```json
{
  "workloadId": "uuid",
  "thresholdUsd": 900,
  "alertOnAnomalyPercent": 20
}
```

`GET /alerts?workloadId=uuid`

Response:

```json
[
  {
    "id": "uuid",
    "workloadId": "uuid",
    "budgetId": "uuid",
    "alertType": "budget_threshold",
    "message": "Modeled monthly cost $950.00 exceeds budget threshold $900.00 using AZURE as the current lowest-cost provider.",
    "thresholdUsd": 900,
    "observedUsd": 950,
    "dismissed": false,
    "triggeredAt": "2026-06-30T00:00:00.000Z"
  }
]
```

`PATCH /alerts/:id`

Body:

```json
{ "dismissed": true }
```

Alert semantics:

- Alerts are generated by the scheduled `alert-evaluator` job.
- Alerts are modeled estimates from cached pricing, not actual cloud billing spend.
- Week-over-week anomalies use stored modeled-cost observations.

## Share Links

`POST /share-links`

Body:

```json
{
  "workloadId": "uuid",
  "watermark": true,
  "expiresInDays": 30
}
```

Response:

```json
{
  "token": "public-token",
  "url": "/api/v1/share/public-token"
}
```

`GET /share/:token`

Response:

```json
{
  "token": "public-token",
  "watermark": true,
  "expiresAt": "2026-07-30T00:00:00.000Z",
  "workload": {},
  "breakdown": {}
}
```

Error cases:

- Expired, revoked, or missing tokens return `404`.
- Shared payload is scoped to the single workload and its comparison breakdown.

## Exchange Rates

`GET /exchange-rates?base=USD`

Response:

```json
{
  "base": "USD",
  "lastUpdated": "2026-06-30T00:00:00.000Z",
  "rates": {
    "EUR": 0.87673,
    "GBP": 0.75587
  }
}
```

Notes:

- Rates are cached by the scheduled `currency-sync` job.
- If no sync has run yet, `rates` may be `{}` and `lastUpdated` will be absent.
